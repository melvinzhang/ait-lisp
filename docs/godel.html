Elegant S-expressions cannot be proved elegant🔗

A #lang ait/scribble port of godel.l, from Chaitin’s The Limits of Mathematics. Each claim below is checked while this document is built: run racket -S src lm/godel.scrbl to check it, or raco scribble to render it.

1 The claim🔗

An S-expression is elegant if no smaller S-expression has the same value. A formal axiomatic system (FAS) is modelled as a LISP expression that displays the S-expressions it proves elegant. Its LISP complexity \(N\) is at most its size.

Theorem. A formal axiomatic system of LISP complexity \(N\) cannot prove that any S-expression of size greater than \(N + 410\) is elegant.

2 The searcher🔗

The proof is a program. Given a FAS, it runs it for longer and longer, waiting for a theorem “\(s\) is elegant” with \(\mathrm{size}(s) > n\), and then evaluates \(s\). Here the FAS and the constant are holes:

let (examine x)

    if atom x  false

    if < n size car x  car x

    (examine cdr x)

let fas '{fas}

let n + {overhead} size fas

let t 0

let (loop)

  let v try t fas nil

  let s (examine caddr v)

  if s eval s

  if = success car v failure

  let t + t 1

  (loop)

(loop)

searcher: size 407 outside the holes {overhead}, {fas}

For the argument to work, \(n\) must be the searcher’s own size: the size of the FAS plus everything else. Everything else is the searcher’s overhead, which includes the digits of the constant itself. godel.l types the constant 410; here fix-overhead derives it as the least constant at least as large as the overhead it creates.

✓ the searcher's overhead c ⇒ 410

The constant does not depend on the FAS: the expression’s size is always \(\mathrm{size}(\mathit{FAS}) + c\).

✓ size(expression) = size(FAS) + c, for four different FASes [4 cases]

Proof. Suppose the FAS has complexity \(N\) and proves that some \(s\) with \(\mathrm{size}(s) > N + c\) is elegant. Plug the FAS’s elegant expression, of size \(N\), into the searcher. The result has size \(N + c\), and it eventually finds \(s\) and evaluates it. So it has the same value as \(s\) while being smaller than \(s\): \(s\) is not elegant, and the FAS proved something false.
